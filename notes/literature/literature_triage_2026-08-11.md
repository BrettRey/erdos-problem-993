## FLAG for Brett

**2605.02193 (Du, Heilman, Panova), methodology point only, no S1 breakthrough.** This paper is about dominating-set sequences, not independent-set sequences, so it does not bear on the S1 threshold question directly. But it reuses and modifies Ramos-Sun's PatternBoost search code (the same tool underlying `arxiv_2510_18826`, already central to this project) and reports a concrete tuning change: the reward function's index $k$ need not be pinned at $n/2$ as in Ramos-Sun; it suffices to let $k$ depend on the first nonzero index of the sequence (quote above, lines 190-195). If the project ever reruns or extends a PatternBoost-style search for non-unimodal (as opposed to merely non-log-concave) trees, this is a directly transferable implementation detail worth checking against the project's own search code before assuming Ramos-Sun's fixed-$k$ choice is necessary.

No other candidate produced an S1 hit (a log-concavity or unimodality break in an independence polynomial of a tree at any index, let alone below the Levit-Mandrescu threshold $\lceil(2\alpha-1)/3\rceil$), and no candidate proved a new unimodality/log-concavity result for a tree family or offered a new invariant stable under the project's DP recursions.
