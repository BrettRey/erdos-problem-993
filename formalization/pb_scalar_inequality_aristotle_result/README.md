# Proposition 3.1 (scalar inequality) — Lean 4 formalization

**Self-assessment: COMPLETE.** G0 (`scalar_inequality`), G1 (`scalar_inequality_compact`) and
G2 (`scalar_inequality_large`) are proved in Lean 4.28.0 / Mathlib v4.28.0, with the
statements exactly as given. There is no `sorry`, `admit`, new `axiom`, `implemented_by` or
`native_decide`. `lake build` succeeds.

These are the three standard axioms. `Lean.ofReduceBool` does not appear: the finite rational

No refutation was found. Every printed identity checked (listed below) holds exactly, and
every Bernstein coefficient in the certificate file is positive.

## Proof route

* **G2 (`H ≥ 16`)** follows Section 4.2 of the paper step by step: triangular cells `J ≥ 5`,
  the Weierstrass bound `b_r ≥ λ_r`, the closed forms `S̃_J` and `T̃_J`, the quartic `N_J`, the
  `J = 5` Bernstein coefficients, and the `J ≥ 6` identity `β_i = μ_i π_i(u)/2880`. Each of
  these is a Lean theorem proved by `field_simp`/`ring`.
* **G1 (`3 < H ≤ 16`)** covers the same 13 cells as the paper but uses a different exact
  method, which is shorter to check:
  * For fixed `K`, every weight `R r` and `L r` is nonnegative and nonincreasing in `δ` while
    `(K+1)δ ≤ 1` (`LR_antitone`). Because `A` is monotone in nonnegative weights (`Aw_mono`),
    `A δ K` is nonincreasing in `δ` (`A_antitone`).
  * The target `(3+δ)/(4δ²)` is also nonincreasing in `δ`.
  * So on any sub-interval `[d_lo, d_hi]` it is enough to check one rational inequality,
    `(3+d_lo)/(4 d_lo²) ≤ A d_hi K`. Lean evaluates it exactly in `ℚ` (`decide +kernel`) after
    the pairwise identity rewrites `A` as `s0·s2 − s1²` (`A_formula`, `Aq_cast`).
  * Cell `K = m` is `δ ∈ [1/(m+2), 1/(m+1)]`, i.e. `H ∈ [m, m+1]`. The hypotheses
    `(K+1)δ < 1 ≤ (K+2)δ` with `K = m` put `δ` in `[1/(m+2), 1/(m+1))`, i.e. `H ∈ (m, m+1]`,
    so each cell is used with the right value of `K`. This settles the `K = m` versus
    `K = m − 1` boundary question without any special case.
  * Cell `[3,4]` (`K = 3`, unsymmetrized weights) needs 20 equal sub-intervals of
    `[1/5, 1/4]`. Each cell `m = 4, …, 15` (also unsymmetrized) needs only one check.
* **Paper's compact-range certificate, also checked** (not needed for G0):
  * the printed identity `A − Q = P(H)/(4H⁵(H+1)³)` for the cell `[3,4]`;
  * for all 13 cells of the data file: the cleared-numerator identity, the Bernstein
    expansion identity, and positivity of all 275 coefficients;
  * from these, each cell by the paper's own route (`cell3_paper`, `cellm_paper`).

  One limit on this check: for `m ≥ 4`, `cellm_paper` proves `Q(H) ≤ S_m T_m` on `[m, m+1]`
  as a statement about `S_m` and `T_m`. It is not connected to `A δ K` in Lean; G1 uses the
  monotonicity route above instead.
